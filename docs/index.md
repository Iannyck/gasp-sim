# gasp-sim

Agent-based simulator testing whether a gamified affective social proxy (GASP, a virtual
pet) can break the spiral of silence in remote Agile teams.

```{warning}
This project is at an early stage. The repository currently contains only the project
skeleton; the simulation engine and the GASP model are being written.
```

## Documentation contents

- **Architecture Decision Records (ADRs):** the structural decisions behind the simulator,
  with their context, the alternatives considered and their consequences.
- **Model specification (ODD protocol):** to be added in English in a later step.
- **User guide and extension guide:** to be added once the simulator can run.
